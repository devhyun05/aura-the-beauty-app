1. Overview

영상 개요와 레퍼런스 목적

회의 목적

이 사이트는 영상을 단순 감상하는 공간이 아니라, 우리 최종 발표에 적용할 디자인 결정, 대본 문장, 메시지 순서, 데모 연결 방식을 빠르게 합의하기 위한 분석 보드입니다.

검증 기준

영상에서 확인한 장면만 근거로 기록하고, 확인하지 못한 내용은 "가정" 또는 "추가 확인 필요"로 표시합니다. transcript가 없으면 발화 요지는 직접 받아 적습니다.

2. Presentation design

발표 디자인 인사이트

첫 화면 신호

첫 10초에 주제, 기대 효과, 발표자의 관점을 어떤 시각 신호로 고정하는지 확인합니다.

슬라이드 밀도

텍스트가 설명을 대신하는지, 발표자의 말과 화면이 서로 보완하는지 구분합니다.

전환 리듬

문제 제기, 근거, 예시, 결론 사이의 화면 전환 속도와 강조 장치를 기록합니다.

데모/증거 배치

실제 화면, 수치, 비교 장면이 메시지 설득력을 높이는 위치를 확인합니다.

3. Script and message

발표 대본/메시지 전달 방식 분석

메시지 단위

한 슬라이드에서 하나의 주장만 전달하는지, 핵심 문장을 반복해 청중의 기억에 남기는지 확인합니다.

말의 연결

"왜 중요한가", "그래서 무엇을 만들었나", "청중이 무엇을 기억해야 하나"가 자연스럽게 이어지는지 봅니다.

4. Content structure

내용 구성 분석

  1. Hook청중이 바로 이해할 문제 또는 장면으로 시작하는지 확인
  2. Context왜 지금 이 문제가 중요한지 배경을 짧게 고정
  3. Solution핵심 아이디어와 제품/서비스의 차별점 제시
  4. Evidence데모, 수치, 사용자 장면, 비교 자료로 설득 보강
  5. Close최종 메시지와 다음 행동을 기억 가능한 문장으로 마무리
