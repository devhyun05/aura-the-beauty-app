# AR 필터 화면 기능 상세 기획서

작성일: 2026-06-26

이 문서는 AR 필터 적용 화면에 대해 대화에서 결정한 기능, 용어, UI 구조, 상태 동작을 정리한 상세 기획서다. 현재 단계의 구현 범위는 모바일 프론트엔드 UI/UX와 mock 상태 처리이며, 실제 Unity AR, ARKit/ARCore, AI 추천 로직, 백엔드 API 연동은 포함하지 않는다.

## 1. 배경과 목표

AR 필터 화면은 사용자가 추천 또는 저장된 메이크업 필터를 얼굴에 실시간으로 적용해 보고, 부위별 옵션을 조합해 새로운 필터 상태를 만든 뒤 저장할 수 있는 화면이다.

초기 화면은 전체 메이크업 스타일을 고르는 구조에 가까웠지만, 대화 과정에서 다음 방향으로 정리했다.

- 전체 얼굴에는 완성된 조합 단위인 `스타일`을 적용한다.
- 눈, 립, 윤곽 등 개별 부위에는 부위별 조합 단위인 `프리셋`을 적용한다.
- 사용자는 `컬러`, `타입`, `질감`, `형태`를 개별적으로 조정할 수 있다.
- 개별 옵션을 하나라도 수정하면 기존에 선택되어 있던 전체 `스타일`은 선택 해제된다.
- 수정된 조합은 저장 버튼을 통해 필터 저장 화면으로 이어진다.

### 1.1 대화 결정 히스토리 요약

이번 기획은 다음 순서로 정리되었다.

1. AR 필터 적용 화면에서 `얼굴 부위`, `스타일 옵션` 라벨을 제거하기로 했다.
2. `기본`, `반반 가이드` 탭 높이를 크게 줄여 AR 프리뷰를 더 많이 보이게 하기로 했다.
3. 메이크업 스타일 선택 카드는 사진과 사진 아래 스타일 이름만 보여주는 단순 카드로 정리하기로 했다.
4. 적용 화면에 있던 `위치 조정`, `스타일 조정` 버튼은 모두 제거하기로 했다.
5. `컬러`, `타입`, `질감` 탭 앞에 처음에는 `위치` 탭을 추가하는 안을 검토했다.
6. 사용자가 `위치`, `컬러`, `타입`, `질감` 중 하나를 선택하면 기존 스타일 선택 카드 영역이 해당 옵션을 고르는 카드 영역으로 바뀌는 구조를 정했다.
7. `위치`가 단순 좌표 이동처럼 들려 직관성이 부족하다는 점을 검토했고, 메이크업 레이어의 랜드마크 적용 모양이라는 의미를 살리기 위해 최종 용어를 `형태`로 바꿨다.
8. 옵션 그룹 순서는 `컬러`, `타입`, `질감`, `형태`로 정했다가, 최종적으로 전체와 개별 부위의 역할을 다시 나누며 아래 구조로 확정했다.
9. 전체 부위에는 `스타일`, `형태` 칩만 둔다.
10. 개별 부위에는 `프리셋`, `컬러`, `타입`, `질감`, `형태` 칩을 둔다.
11. 모든 카드 목록의 첫 번째에는 `원본` 카드를 넣기로 했다.
12. `원본`은 현재 부위 필터를 적용하지 않거나, `형태`에서는 기본 랜드마크 상태로 되돌리는 카드로 정의했다.
13. `저장` 버튼과 `형태 수정` 버튼을 하단 컨트롤 패널 안에 넣기로 했다.
14. 전체 스타일을 선택한 뒤 전체 스타일 외 옵션을 하나라도 수정하면 전체 스타일 선택을 해제하고 저장 버튼을 활성화하기로 했다.
15. 새 전체 스타일을 선택하면 다시 해당 스타일 선택 상태로 전환하기로 했다.
16. 전체 얼굴의 완성형 조합과 개별 부위의 조합을 모두 `스타일`이라고 부르면 어색하므로 용어를 분리하기로 했다.
17. `룩`은 메이크업 외 영역에서도 넓게 쓰이므로 쓰지 않기로 했다.
18. 최종 사용자-facing 용어는 전체 조합 `스타일`, 부위별 조합 `프리셋`으로 확정했다.
19. 코드 변수와 타입에는 `makeup`을 넣어 도메인 의미를 명확히 하기로 했다.

## 2. 최종 용어 정의

### 2.1 사용자에게 보이는 용어

`스타일`

전체 얼굴 메이크업에 적용되는 완성형 조합이다. 여러 부위의 컬러, 타입, 질감, 형태가 조합되어 만들어진 전체 얼굴 프리셋에 해당한다. 화면에서는 `전체` 부위를 선택했을 때 사용하는 주요 선택 단위다.

`프리셋`

눈, 립, 윤곽, 베이스 같은 특정 메이크업 부위에 적용되는 조합 단위다. 특정 부위의 컬러, 타입, 질감, 형태가 묶여 있는 부위별 설정값으로 본다. 화면에서는 전체가 아닌 개별 부위를 선택했을 때 사용하는 주요 선택 단위다.

`컬러`

선택된 부위 또는 프리셋에 적용되는 색상 옵션이다. 립 컬러, 블러셔 톤, 아이 컬러처럼 색상 자체를 의미한다.

`타입`

같은 부위 안에서 메이크업 표현 방식이나 제품 계열을 구분하는 옵션이다. 예를 들어 립스틱, 틴트, 글로스처럼 적용 방식 또는 카테고리 차이를 표현할 수 있다.

`질감`

메이크업의 표면 표현이다. 매트, 글로우, 세미글로우, 쉬머처럼 같은 컬러와 타입이라도 마무리감이 달라지는 옵션이다.

`형태`

메이크업 레이어가 얼굴 랜드마크에 맞춰 적용되는 모양과 배치 패턴이다. 초기에 `위치`라는 표현을 검토했지만, 단순 좌표 이동보다 랜드마크 기반 적용 모양을 다루는 개념이므로 최종 용어는 `형태`로 결정했다.

`원본`

모든 옵션 선택 카드 목록의 첫 번째 카드다. 선택 시 현재 선택 중인 메이크업 부위의 필터 적용을 끄거나 기본 상태로 되돌린다. 단, 현재 옵션 그룹이 `형태`일 때는 해당 부위의 형태를 기본 랜드마크 상태로 되돌리는 의미다.

`형태 수정`

형태 옵션을 더 세밀하게 조정하는 화면으로 들어가는 액션이다. 사용자는 메이크업 레이어의 랜드마크 기반 형태를 조정하고, 이후 저장된 형태를 컬러, 타입, 질감처럼 조합 가능한 옵션으로 사용할 수 있다.

`저장`

현재 수정된 메이크업 필터 조합을 저장하는 액션이다. 저장 버튼을 누르면 필터 저장 화면으로 이동한다.

### 2.2 사용하지 않기로 한 용어

`위치`

처음에는 컬러, 타입, 질감 앞에 `위치` 탭을 추가하는 안을 검토했다. 하지만 실제 의미가 단순 좌표 이동이 아니라 얼굴 랜드마크를 기준으로 메이크업 레이어의 적용 모양을 바꾸는 것이므로 직관성이 부족하다고 판단했다. 최종적으로 `형태`로 대체한다.

`룩`

전체 얼굴 단위의 메이크업 표현을 `룩`으로 부르는 방안도 검토했다. 하지만 `룩`은 메이크업이 아닌 패션, 스타일링, 전체 이미지 표현에서도 넓게 쓰이는 단어라 AR 필터 화면의 옵션 체계에서는 사용하지 않는다.

`스타일 옵션`

기존 화면에 있던 섹션 라벨성 문구다. 최종 UI에서는 카드와 칩 자체로 맥락을 전달하므로 `스타일 옵션` 라벨은 제거한다.

`얼굴 부위`

기존 화면에 있던 섹션 라벨이다. 최종 UI에서는 부위 칩 목록만 보여주고 별도 라벨은 제거한다.

### 2.3 코드 네이밍 원칙

사용자에게 보이는 문구는 `스타일`, `프리셋`, `컬러`, `타입`, `질감`, `형태`를 사용한다.

코드 변수와 타입에는 의미가 흔들리지 않도록 `makeup`을 포함한다.

권장 예시는 다음과 같다.

- `makeupStyle`
- `makeupPreset`
- `selectedMakeupStyleCardId`
- `selectedMakeupPresetCardId`
- `selectedMakeupOptionGroup`
- `hasUnsavedMakeupChanges`
- `MakeupShapeOption`
- `MakeupFilter`

React Native의 `style` prop 또는 `StyleSheet`의 `styles` 객체는 도메인 용어가 아니므로 이 규칙의 정리 대상이 아니다.

## 3. 화면 구성

### 3.1 상단 AR 영역

상단은 실시간 카메라 기반 AR 프리뷰 영역이다.

- 배경은 라이브 카메라 레이어로 처리한다.
- 선택된 메이크업 컬러와 옵션이 AR 프리뷰 위에 반영된다.
- 뒤로가기 버튼만 유지한다.
- 기존 `위치 조정`, `스타일 조정` 버튼은 제거한다.
- 화면 설명성 헤더 문구는 표시하지 않는다.

### 3.2 가이드 모드 탭

AR 적용 방식은 `기본`, `반반 가이드` 두 가지 탭으로 제공한다.

- 탭 높이는 기존보다 크게 줄여 AR 화면을 덜 가리게 한다.
- 현재 기준 높이는 24px 수준이다.
- `반반 가이드` 선택 시 좌우 비교 모드를 제공한다.
- 좌우 비교 탭도 같은 낮은 높이 체계를 따른다.

### 3.3 하단 컨트롤 패널

하단 패널은 사용자가 실제로 필터 옵션을 고르는 작업 영역이다.

표시 순서는 다음과 같다.

1. 메이크업 부위 칩 목록
2. 선택된 부위에 따른 옵션 그룹 칩 목록
3. 선택된 옵션 그룹의 카드 목록
4. `형태 수정`, `저장` 액션 버튼
5. 사진/동영상 촬영 컨트롤

`얼굴 부위`, `스타일 옵션` 같은 별도 라벨은 표시하지 않는다.

## 4. 부위 선택 규칙

### 4.1 전체

`전체`는 얼굴 전체에 적용되는 메이크업 조합을 다룬다.

전체 선택 시 표시되는 옵션 그룹은 다음과 같다.

```text
스타일, 형태
```

초기 진입 시에는 `스타일` 그룹이 선택되어 있는 상태로 본다. 전체의 `스타일`은 각 부위 옵션들이 조합되어 만들어진 완성형 프리셋이다.

### 4.2 개별 부위

눈, 립, 윤곽, 베이스 등 개별 부위 선택 시 표시되는 옵션 그룹은 다음과 같다.

```text
프리셋, 컬러, 타입, 질감, 형태
```

개별 부위의 `프리셋`은 해당 부위의 컬러, 타입, 질감, 형태가 조합된 부위별 프리셋이다.

## 5. 옵션 그룹별 카드 규칙

모든 옵션 그룹의 카드 UI는 같은 형태를 사용한다.

- 카드 목록의 첫 번째는 항상 `원본` 카드다.
- 카드에는 이미지 또는 프리뷰 영역을 보여준다.
- 카드 하단에는 옵션 이름만 보여준다.
- 기존 스타일 카드에 있던 부가 설명, 강도, 보조 텍스트는 제거한다.
- 카드 형태는 `스타일`, `프리셋`, `컬러`, `타입`, `질감`, `형태` 모두 동일하게 유지한다.

### 5.1 스타일 카드

전체 부위의 `스타일` 그룹에서 표시된다.

- `원본` 카드가 첫 번째로 표시된다.
- 이후 전체 얼굴 메이크업 스타일 카드가 표시된다.
- 각 카드는 사진과 스타일 이름만 표시한다.
- 스타일을 선택하면 전체 메이크업 조합이 해당 스타일로 전환된다.
- 새 전체 스타일을 선택하면 기존 수정 상태는 해당 스타일 선택 상태로 전환된다.

### 5.2 프리셋 카드

개별 부위의 `프리셋` 그룹에서 표시된다.

- `원본` 카드가 첫 번째로 표시된다.
- 이후 해당 부위에 적용 가능한 프리셋 카드가 표시된다.
- 각 카드는 사진과 프리셋 이름만 표시한다.
- 프리셋을 선택하면 해당 부위의 조합이 바뀐다.
- 전체 스타일이 선택되어 있던 상태에서 프리셋을 선택하면 전체 스타일 선택은 해제되고 저장 버튼이 활성화된다.

### 5.3 컬러 카드

선택된 부위 또는 현재 선택된 필터의 컬러 옵션을 보여준다.

- 첫 번째 카드는 `원본`이다.
- 이후 컬러 옵션 카드가 표시된다.
- 컬러 카드도 스타일 카드와 동일한 카드 크기와 구조를 사용한다.
- 프리뷰 영역은 색상 스와치 또는 색상 이미지로 표현할 수 있다.

### 5.4 타입 카드

선택된 부위 또는 현재 선택된 필터의 타입 옵션을 보여준다.

- 첫 번째 카드는 `원본`이다.
- 이후 타입 옵션 카드가 표시된다.
- 타입 카드도 사진 또는 타입을 암시하는 프리뷰와 이름만 표시한다.

### 5.5 질감 카드

선택된 부위 또는 현재 선택된 필터의 질감 옵션을 보여준다.

- 첫 번째 카드는 `원본`이다.
- 이후 질감 옵션 카드가 표시된다.
- 질감 카드도 사진 또는 질감을 암시하는 프리뷰와 이름만 표시한다.

### 5.6 형태 카드

선택된 부위 또는 전체 얼굴의 형태 옵션을 보여준다.

- 첫 번째 카드는 `원본`이다.
- 이후 형태 옵션 카드가 표시된다.
- 형태는 단순 위치값이 아니라 메이크업 레이어의 랜드마크 기반 적용 모양이다.
- 같은 스타일 또는 프리셋이라도 형태가 바뀌면 얼굴에 적용되는 모양이 달라진다.

## 6. `원본` 카드 동작

`원본` 카드는 어떤 옵션 그룹을 선택하든 카드 목록의 첫 번째에 있어야 한다.

옵션 그룹별 의미는 다음과 같다.

- `스타일`에서 원본 선택: 전체 얼굴에 현재 선택된 전체 스타일 필터를 적용하지 않는다.
- `프리셋`에서 원본 선택: 현재 선택된 부위의 프리셋 필터를 적용하지 않는다.
- `컬러`에서 원본 선택: 현재 선택된 부위의 컬러 적용을 기본 또는 미적용 상태로 되돌린다.
- `타입`에서 원본 선택: 현재 선택된 부위의 타입 적용을 기본 또는 미적용 상태로 되돌린다.
- `질감`에서 원본 선택: 현재 선택된 부위의 질감 적용을 기본 또는 미적용 상태로 되돌린다.
- `형태`에서 원본 선택: 현재 선택된 부위의 형태를 기본 랜드마크 상태로 되돌린다.

`원본`은 삭제나 초기화 버튼이 아니라 카드 선택지 중 하나다. 따라서 다른 옵션 카드와 동일한 카드 UI와 선택 상태를 가진다.

## 7. 전체 스타일 선택 해제와 저장 버튼 규칙

### 7.1 기본 상태

AR 필터 화면에 처음 진입하면 기본 전체 스타일이 선택된 상태로 시작한다.

이 상태에서는 아직 사용자가 직접 조합을 수정한 것이 아니므로 저장 버튼은 비활성화된다.

### 7.2 전체 스타일 선택

사용자가 전체 부위에서 특정 `스타일` 카드를 선택하면 다음 상태가 된다.

- 선택된 전체 스타일이 활성 카드로 표시된다.
- 개별 수정 상태는 초기화된 것으로 본다.
- 저장 버튼은 비활성화된다.

### 7.3 전체 스타일 외 옵션 수정

전체 스타일이 선택된 상태에서 아래 항목 중 하나라도 수정하면 선택되어 있던 전체 스타일은 선택 해제된다.

- 개별 부위의 프리셋 선택
- 컬러 선택
- 타입 선택
- 질감 선택
- 형태 선택
- 원본 카드 선택을 통한 부위별 적용 해제 또는 형태 초기화
- 형태 수정 화면에서 저장된 형태 변경

이때 저장 버튼은 활성화된다.

### 7.4 새 전체 스타일 재선택

수정 상태가 있더라도 사용자가 다시 전체 부위에서 다른 `스타일`을 선택하면 다음 상태로 전환된다.

- 새 전체 스타일이 선택 상태가 된다.
- 기존 개별 수정 상태는 해당 스타일 기준 상태로 덮어쓴 것으로 본다.
- 저장 버튼은 다시 비활성화된다.

## 8. 형태 수정 기능

`형태 수정` 버튼은 하단 옵션 패널 안에서 저장 버튼과 함께 제공한다.

형태 수정 화면의 목적은 다음과 같다.

- 메이크업 레이어가 얼굴 랜드마크에 붙는 기준을 조정한다.
- 좌우 이동, 상하 이동, 크기, 각도 같은 값을 조정할 수 있다.
- 사용자는 조정한 형태를 저장하고 이후 형태 옵션으로 재사용할 수 있다.
- 형태는 컬러, 타입, 질감과 같은 조합 가능한 옵션으로 취급한다.

형태 수정은 `위치 조정`이라는 이름을 사용하지 않는다. 화면 문구는 `형태 수정`을 사용하고, 세부 조정 항목은 필요한 경우 `좌우 이동`, `상하 이동`, `크기`, `각도`처럼 조작 단위로 표현한다.

## 9. 저장 기능

저장 버튼은 사용자가 전체 스타일이 아닌 개별 조합을 만들었을 때 활성화된다.

저장 버튼을 누르면 필터 저장 화면으로 이동한다. 현재 모바일 앱의 기존 저장 화면 흐름에서는 `ExtractedMakeupStyleSaveForm` route를 재사용할 수 있다. 이후 실제 제품 구조가 정리되면 AR 필터 전용 저장 화면 또는 공통 메이크업 스타일 저장 화면으로 분리할 수 있다.

저장 화면으로 넘겨야 하는 데이터는 다음과 같다.

- 선택된 전체 스타일 ID 또는 선택 해제 상태
- 선택된 부위별 프리셋 ID
- 선택된 컬러 ID
- 선택된 타입 ID
- 선택된 질감 ID
- 선택된 형태 ID 또는 직접 조정된 형태 값
- 원본 선택 여부
- 저장할 미리보기 이미지 또는 캡처 결과

## 10. 촬영 기능

AR 필터 적용 화면은 옵션 조정뿐 아니라 촬영 화면이기도 하다.

- 사진 모드와 동영상 모드를 제공한다.
- 촬영 버튼은 중앙 주요 액션으로 유지한다.
- 사진 모드에서는 AR 사진 촬영 후 후속 화면 또는 홈으로 이동할 수 있다.
- 동영상 모드에서는 AR 동영상 촬영 후 후속 화면 또는 홈으로 이동할 수 있다.
- 촬영 기능은 필터 저장 기능과 별도의 액션이다.

## 11. 상태 모델 초안

프론트엔드 상태는 다음 기준으로 관리한다.

```ts
type ARMakeupOptionGroupId =
  | 'makeupStyle'
  | 'makeupPreset'
  | 'color'
  | 'type'
  | 'texture'
  | 'shape';
```

주요 상태 예시는 다음과 같다.

- `selectedFacePartId`: 현재 선택된 전체 또는 개별 부위
- `selectedMakeupOptionGroup`: 현재 선택된 옵션 그룹
- `selectedMakeupStyleCardId`: 전체 스타일 카드 선택값
- `selectedMakeupPresetCardId`: 개별 부위 프리셋 카드 선택값
- `selectedColorId`: 컬러 선택값
- `selectedTypeId`: 타입 선택값
- `selectedTextureId`: 질감 선택값
- `selectedShapeId`: 형태 선택값
- `hasUnsavedMakeupChanges`: 저장 가능한 사용자 수정 여부

형태 옵션 데이터는 이후 다음 정보를 포함할 수 있다.

- 형태 ID
- 표시 이름
- 적용 부위
- 기준 랜드마크 세트
- 좌우 이동값
- 상하 이동값
- 크기 조정값
- 회전값
- 프리뷰 이미지 또는 프리뷰 생성 정보

## 12. 접근성 및 UI 문구 규칙

버튼과 카드의 접근성 라벨은 사용자가 듣기만 해도 동작을 이해할 수 있어야 한다.

권장 라벨 예시는 다음과 같다.

- `원본 스타일 선택`
- `원본 프리셋 선택`
- `원본 컬러 선택`
- `원본 타입 선택`
- `원본 질감 선택`
- `원본 형태 선택`
- `메이크업 형태 수정 화면 열기`
- `현재 메이크업 필터 저장하기`

사용자에게 보이는 섹션 설명 문구는 최소화한다. 칩과 카드 이름으로 충분히 이해되는 영역에는 `얼굴 부위`, `스타일 옵션` 같은 라벨을 두지 않는다.

## 13. 디자인 방향

디자인 톤은 기존 모바일 가이드의 Premium K-beauty tech 방향을 따른다.

- 블랙과 화이트 중심의 차분한 UI를 유지한다.
- 옵션 카드는 과한 장식 없이 사진 또는 프리뷰와 이름만 보여준다.
- 카드 안 텍스트는 한 줄로 자연스럽게 맞춘다.
- 탭과 칩은 AR 화면을 가리지 않도록 낮고 간결하게 유지한다.
- 카드의 형태와 크기는 옵션 그룹이 바뀌어도 일관되게 유지한다.
- `형태 수정`, `저장` 버튼은 옵션 선택 흐름을 방해하지 않는 위치에 둔다.

## 14. 완료 기준

다음 조건을 만족하면 AR 필터 화면의 현재 기획 범위가 충족된 것으로 본다.

- 적용 화면에서 `얼굴 부위`, `스타일 옵션` 라벨이 보이지 않는다.
- `기본`, `반반 가이드` 탭 높이가 낮아져 AR 프리뷰를 과하게 가리지 않는다.
- `위치 조정`, `스타일 조정` 버튼이 적용 화면에서 제거된다.
- 하단 옵션 그룹은 전체 선택 시 `스타일`, `형태`만 보여준다.
- 하단 옵션 그룹은 개별 부위 선택 시 `프리셋`, `컬러`, `타입`, `질감`, `형태`를 보여준다.
- 모든 옵션 그룹 카드 목록의 첫 번째 카드는 `원본`이다.
- 모든 옵션 카드가 사진 또는 프리뷰와 이름만 보여주는 같은 구조를 사용한다.
- 전체 스타일 선택 후 개별 옵션을 수정하면 전체 스타일 선택이 해제된다.
- 개별 옵션 수정 후 저장 버튼이 활성화된다.
- 새 전체 스타일을 선택하면 해당 스타일 선택 상태로 전환되고 저장 버튼은 비활성화된다.
- `형태 수정` 버튼이 제공되고 형태 수정 화면으로 이동한다.
- 저장 버튼을 누르면 필터 저장 화면으로 이동한다.
- 사용자-facing 문구에서 `위치` 대신 `형태`를 사용한다.
- 코드 변수와 타입에서 메이크업 도메인 상태는 `makeup`을 포함해 의미를 분명히 한다.

## 15. 후속 검토 항목

아래 항목은 현재 기획에서 방향만 정하고, 실제 API 또는 AR 엔진 연동 단계에서 확정한다.

- 저장된 형태 옵션의 정확한 데이터 스키마
- 형태 수정 화면에서 사용자가 직접 만든 형태를 카드 목록에 즉시 추가할지 여부
- 전체 스타일 선택 시 기존 개별 수정 상태를 완전히 폐기할지, 히스토리로 보관할지 여부
- `원본` 선택 상태를 저장 가능한 사용자 커스텀으로 볼지 여부
- AR 필터 전용 저장 화면을 만들지, 기존 메이크업 스타일 저장 화면을 공통으로 사용할지 여부
- 실제 Unity 또는 네이티브 AR 모듈과 프론트엔드 mock 상태를 연결하는 인터페이스
