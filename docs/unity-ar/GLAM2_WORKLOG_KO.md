- **핵심 발견**: 기존 "회전 금지 세로이동 평탄화"가 도안 구도(부챗살)를 붕괴시킨 주범. 올바른 가공 = **아치 언롤**: 뿌리 곡선(클로징 blob 가장자리, 중간 70% 컬럼만 파라볼라 피팅)을 따라 호길이 파라미터화 후 **국소 법선 방향으로 샘플** — 각 털이 접선각만큼 회전되며 펴지고, 메시가 눈매 곡선을 되입힐 때 원본 부채꼴이 복원된다. 구현: `scratchpad/lash_pair_pipeline.py` (범용: 셀 크롭→위/아래 연결요소 분리→각각 언롤→위 512×256 뿌리 하단 / 아래 512×128 뿌리 상단)
- **추가 교정 3개**: ① `mascaraLength` 1.9→**1.0** (1.9는 텍스처 세로 1.9배 스트레치 = 컬을 펴버림 — "빳빳하다" 판정의 기하 원인) ② 경계 밖 샘플은 clamp가 아니라 **0** (clamp 시 가장자리 픽셀이 직선 줄무늬로 번짐) ③ 뿌리 띠는 2px 앵커만 (두꺼운 커넥터 금지 — 라이너가 어차피 덮음)

- **추출법 v3 (확정 레시피)** — `scratchpad/lash_pipe3.py`:
  1. 셀 크롭 (파일당 도안 1개, 시트면 칸 좌표) → 필요 시 좌우 미러 (**꼬리=오른쪽** 규약)
  2. 4배 슈퍼샘플 + 배경 적응 알파: 테두리 중앙값=배경, `(bg-g)/(bg-ink)` — 흰/회색/체커 배경 공용, 게인은 옅은 도안만 1.3~1.6
  3. 연결요소로 위/아래 자동 분리 (무게중심 y 기준, 최소 크기 필터로 워터마크 제거)
  4. 뿌리 곡선: 클로징 blob 가장자리에 파라볼라 (중간 70% 컬럼만 — 꼬리 처짐 오염 방지)
  5. **아치 언롤**: 호길이 파라미터화 + 국소 법선 샘플 (회전 포함 — 세로이동만 하면 구도 붕괴), **경계 밖 샘플=0** (clamp면 줄무늬)
  6. 내용물 bbox 크롭 → **폭 512 완전 충전** (우측정렬 패딩 금지 — 눈머리 공백 생김), 위 256/아래 128, 뿌리 앵커 2px만
  7. 도안 비례 r(=높이/호길이) 기록 → 길이 = 3.0×r (하한 1.0) 로 도안 비례 재현
- **실격된 후처리 5종 (재시도 금지)**: 회전 없는 평탄화(부채 구도 파괴) / 세로 1.9 스트레치(컬 폄) / 침식·감마 씬닝(회색 얼룩) / 스켈레톤 재획(철사 인공물) / 시프트 복제 밀도 보강(복붙 티 + 도안 간격 리듬 파괴) / 팁 세로 압축 과다(컬 갈고리 소실 — 45%→40%는 과함, 완만하게만)
- **핵심 교훈**: 픽셀 수술은 전부 원본 충실도와 맞바꿈 — **가공이 아니라 소스 선별이 답** (DL1 통과 이유 = 도안이 가는 털·균등 간격·적정 길이를 원래 충족). 부족한 룩은 고해상 소스 재수급으로 해결할 것
- **세션 함정 추가**: 대용량 배치 전 디스크 확인 (DerivedData 12GB로 ENOSPC 재발 — Bash 출력 파일도 못 써서 Unity execute_code로 우회 정리)

### 2026-07-21 / Phase 3 립 착수 — 캡처 함정 3종 해결 후 강도 사다리 확보
- **함정 ① renderer.material 읽기 파괴**: 진단 코드에서 `.material`을 *읽기만 해도* 머티리얼이 복제·교체되어 렌더러가 스크립트와 분리됨(이후 모든 파라미터 적용이 화면에 안 보임). **진단은 반드시 `.sharedMaterial`**. 분리됐으면 스크립트 보유 머티리얼을 `sharedMaterial`에 재대입으로 복구
- **함정 ② GrabPass는 수동 RT 캡처에 안 잡힘**: Lip/EyelinerStyle 등 GrabPass 셰이더는 `cam.Render()`→RT 캡처에서 누락(스티커 셰이더인 LashTexture만 보임). **립 심사는 게임 뷰 스크린샷**(ScreenCapture) 필수, OnGUI 디버그 2종(FaceTrackingStatusReporter·MakeupRegionDebugControls) 끄고 찍기
