# 수염 시뮬레이션 — 테스트 데이터 정책 (v1)

개발·튜닝 단계에서 사용하는 얼굴 사진에 대한 규칙. MVP 출시 전 사용자 대상 정책(동의 화면 문구)은 이 문서를 기반으로 별도 작성한다.

## 원칙

1. **로컬 전용**: 테스트 사진은 `tools/beard-simulation-lab/samples/`(gitignore됨)에만 둔다. git 커밋, 클라우드 업로드, 외부 전송 금지. dev API(`server.py`)는 localhost 바인딩 전용이다.
2. **동의 필수**: 본인 및 지인 사진은 "제모 시뮬레이션 개발 테스트에 사용, 언제든 삭제 요청 가능"을 구두/메시지로 동의받은 것만 사용한다. 동의 철회 시 원본·파생물(마스크, run 산출물) 전부 즉시 삭제.
3. **파생물도 사진이다**: `outputs/runs/`의 마스크·보정 결과·오버레이는 원본과 동일하게 취급한다(gitignore됨). 공유 가능한 것은 **지표(metrics.json 수치)와 판정 기록뿐** — `reports/`에는 숫자만 요약한다.
4. **학습 미사용**: 수집 사진을 모델 학습에 사용하지 않는다(향후 커스텀 seg 학습을 하게 되면 별도 동의를 다시 받는다).
5. **보존 기간**: 튜닝 완료(게이트 ② 통과) 후 30일 내 samples/outputs 정리. 장기 회귀 테스트용으로 남길 사진은 촬영자 재동의 후 최소 세트(≤10장)만 유지.

## 앱(MVP) 단계에서 지켜야 할 것 (동의 화면 요구사항)

- 사진이 **어디서 처리되는지**(현 단계: 개발자 로컬 서버) 명시
- 결과 이미지는 참고용 합성 이미지이며 의료적 예측이 아님 명시
- 즉시 삭제 버튼 제공, 보존 기간 명시
- 설문에 건강 정보(피부 자극 등) 미포함 — 계약 스키마에서 금지됨
