## 수술 1a — 검출 보호막과 보정 보호막의 분리 · **채택**

"어디를 봐도 되나"와 "어디에 절대 칠하면 안 되나"는 다른 질문인데 같은 마스크였다.
팽창된 `protect_mask`의 **하방 팽창이 입술밑에, 코밑 원반이 인중 위에** 정확히 얹혀 있었다.

- `LowerFaceCrop.detect_protect_mask` 신설(입술 폴리곤 + 축소된 콧구멍 원반, 팽창 없음) → **검출**이 이걸로 클램프
- `protect_mask`(팽창)는 **보정·blend 전용**으로 유지 → 최종 이미지에서 입술 불변
- 신규 필드는 `protect_mask`로 기본값 설정 → 기존 테스트의 수제 crop은 동작 불변

**가드 재정의**: 팽창 마스크 기준으론 정당한 인중 검출이 거부됨(psd02 = 0.056 > 임계 0.02).
실제 입술 폴리곤 기준으로 재면 **9장 전부 0.0000**. 가드의 진짜 계약("입술을 건드리지 마라")을
`crop.lips_mask`로 재정의. blend가 팽창 마스크로 출력을 0으로 만들므로 입술은 **이중 보호**.

## 수술 1b — ROI 폴리곤 상단 절단 수정 · **채택**

`oval[oval[:,1] >= top_y]`로 **점을 걸러낸 뒤** 채우면, 상단이 코밑선이 아니라
**살아남은 최상단 점들을 잇는 직선(현)** 이 된다. 그 현의 위치는 랜드마크 링의 샘플링에 좌우된다.

| | 인중 높이 | 잘린 양 |
|---|---:|---:|
| pic2 | 34px | 21px (**62%**) |
| pic3 | 38px | 20px (**53%**) |
| psd01 | 72px | 41px (**57%**) |

→ **전체 타원을 채운 뒤 `y >= top_y`로 자른다.** 의도한 의미 그대로. 수정 후 잘림 9장 전부 0%.
ROI 면적비 0.033~0.113로 폴리곤 뒤엉킴 없음 확인.

  `hard` 22,765px @ P=0.679 vs `shadow` 186,847px @ **P=0.330**. 저주파 shadow 장이 턱 실루엣의
  **기하학적 음영**(얼굴이 목으로 꺾이며 생기는 어두움)을 수염으로 착각한다. Stage 3 융합에서
  C1을 "정밀 판정자"로 쓸 때 이 오염을 반드시 다뤄야 한다.
