## 0. cp6과의 설계 차이 (사전 명시)

1. **판정 대상 = 원시 채움(raw fill)**: cp6은 서빙 계약(비-pass=미출고)대로 ABSTAIN
   타일을 보여 전 패널이 양측 미출고로 퇴화했다. ⑦에서는 **채움이 생산된 사진은
   품질 게이트 판정과 무관하게 원시 채움을 판정자에게 제시**한다(마스크 미발화/입구
   abstain만 ABSTAIN 타일). 품질 게이트·서빙 계약은 **별도 축**으로 기계 기록해
   "게이트 vs 인간" 캘리브레이션 데이터를 얻는다.
2. **차단 기준은 절대 사용성**: 두 팔의 채움 로직·설정은 동일(1024/0.02)하므로 비교
   판정은 회귀 감지용 보고 축이고, 차단은 B 원시 채움의 절대 사용성으로 건다.
3. dense 층 없음(v1 범위 밖 확정), 실사 primary 없음(소진 — §7 상태 로그 참조.
   사용자 제공 셀피가 §6-1 동결 전에 도착하면 primary 층으로 추가 등록 가능).

## 8. 결과 해석 사전 약속

- **합격**: B(입구 게이트 수리본)를 새 frozen baseline으로 승격. 채움 품질의 첫
  홀드아웃 인간 데이터 확보 — R2 교차표를 품질 게이트 재캘리브레이션의 입력으로.

- **K3/K4 실패**(사용성): 현 LaMa 채움 품질이 인간 기준 미달임이 홀드아웃에서 확정
  — **LaMa 얼굴 fine-tune go 결정의 직접 근거**. R2 교차표로 게이트가 이미 이를
  알고 있었는지 확인.
- **K1/K2 실패**: 안전 회귀 — B 기각, 원인 분석 dev로만.
