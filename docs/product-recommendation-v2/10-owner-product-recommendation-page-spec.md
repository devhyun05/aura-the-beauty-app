# 10. 담당 구현 문서: 제품 추천 페이지

작성일: 2026-07-13  
담당 범위: 홈 화면의 `추천 제품` 카테고리에서 진입하는 제품 추천 페이지  
제외 범위: 메이크업 추천 MCP, 메이크업 추천 생성 로직 자체, AR 런타임 엔진 구현

## 1. 담당 변경 요약

이번 담당 범위는 `메이크업 추천 MCP`가 아니라 `추천 제품 페이지`다.

즉, 사용자가 홈 화면의 기능 카테고리에서 `추천 제품`을 누르면 진입하는 화면을 구현한다. 이 페이지는 기존에 있던 `ProductRecommendationScreen`과 `/api/products/recommendations` 흐름을 버리지 않고 가져가며, 그 위에 AR 필터 기반 추천, 시즌 상품, 개인화 추천, 아우라딘 연결을 추가하는 방식으로 확장한다.

아우라딘은 제품 추천 페이지를 대체하는 화면이 아니다. 제품 추천 페이지 안에서 `아우라딘으로 더 자세히 찾아보기`처럼 연결되는 제품 추천 에이전트 진입점이다.

## 2. 구현 목표

제품 추천 페이지의 목표는 사용자가 분석 결과와 AR 필터 경험을 실제 구매 가능한 화장품 탐색으로 연결하도록 돕는 것이다.

핵심 사용 흐름:

```text
홈
→ 추천 제품
→ 제품 추천 페이지
   → 제품 검색
   → AR 필터 기반 추천 제품
   → 서진님만을 위한 추천 제품
   → 시즌 상품
   → 비슷한 컬러 취향 사용자 추천
   → 아우라딘 에이전트로 상세 탐색
   → 좋아요/구매 링크/마이페이지 저장
```

이 페이지는 단순히 상품 목록을 보여주는 화면이 아니라, 사용자의 얼굴진단 리포트, 저장한 AR 필터, 좋아요·검색·클릭 같은 반응 데이터를 바탕으로 추천 이유가 있는 제품을 보여주는 허브다.

## 3. 화면 구성

### 상단바

- 뒤로가기
- 화면 제목: `제품 추천`
- 알림
- 채팅

상단바는 새로 만들기보다 기존 route chrome과 홈에서 쓰는 알림/채팅 icon action을 재사용한다.

### 본문 섹션

1. 제품 검색
   - 브랜드명, 제품명, 카테고리 검색
   - 검색 결과가 없을 때 바로 아우라딘으로 넘기지 않고 `아우라딘에게 물어보기` CTA 제공

2. AR 필터 기반 추천 제품
   - 사용자가 메이크업 추천을 받은 뒤 AR 필터를 적용하고, 색상·제형·강도 등을 조정한 뒤 저장한 필터를 기준으로 제품 추천
   - 립, 블러셔, 아이섀도우, 아이라이너, 베이스처럼 부위별로 추천 분리
   - 한 rail 안에 서로 다른 부위 상품을 섞지 않음
   - 추천 이유 예시:
     - `선택한 립 색상과 가까워요`
     - `글로우 피니시가 비슷해요`
     - `블러셔 영역 기준 추천`

3. 서진님만을 위한 추천 제품
   - AR 필터뿐 아니라 사용자의 좋아요, 검색, 클릭, 저장 기록을 기반으로 추천
   - 데이터가 부족하면 억지로 채우지 않고 숨기거나 안내 문구 표시
   - 개인화 데이터 사용은 동의와 삭제 가능성을 전제로 함

4. 시즌 상품
   - 계절, 유행, 최근 트렌드, 에디터 검수 결과를 바탕으로 추천
   - 예시:
     - `여름 글로우 립`
     - `장마철 세미매트 베이스`
     - `가을 웜 무드 메이크업`
   - 연예인 이름이나 사진은 권리 확인 없이는 전면 사용하지 않음
   - `요즘 많이 팔림`처럼 판매량으로 오해되는 표현 대신 `최근 검색 클릭 추이 상승`, `에디터 검수`처럼 근거를 분리해 표시

5. 비슷한 컬러 취향이 좋아해요
   - 얼굴 사진이나 얼굴 임베딩으로 사용자를 직접 비교하지 않음
   - 얼굴진단 리포트의 퍼스널 컬러, 톤 정보, 동의한 행동 데이터를 넓은 취향 그룹으로 묶어 추천
   - 문구는 `얼굴이 비슷한 분들`보다 `비슷한 컬러 취향이 좋아해요`가 안전함
   - 모수가 부족하면 section 숨김

6. 아우라딘 연결 버튼
   - 기존에 제품 추천 버튼을 누르면 바로 보이던 아우라딘 화면으로 이동하는 진입점
   - 제품 추천 허브 오른쪽 하단에 젤리 orb를 두고, 제품 카드·하단 네비게이션을 가리지 않는 가장자리로 스냅
   - 탭은 대화 화면, 길게 누른 뒤 드래그는 안전 영역 내 위치 이동
   - 역할:
     - 사용자가 자연어로 원하는 제품 조건을 말함
     - 예: `피치빛 크림 블러셔 추천해줘`, `은은한 쉬머 섀도우 찾아줘`
     - 아우라딘이 AR 필터와 얼굴진단 리포트를 참고해 제품을 찾아줌

7. 좋아요 기능
   - 모든 제품 카드에서 좋아요 가능
   - 좋아요한 제품은 마이페이지의 좋아요 제품 모음에서 확인
   - 제품 추천 페이지, 아우라딘, 제품 상세, 마이페이지가 같은 서버 좋아요 저장소를 공유해야 함

## 4. 기존에 가져갈 구현

기존 제품 추천 기능은 삭제된 것이 아니라 진입 경로가 아우라딘으로 바뀐 상태다. 따라서 다음 요소는 재사용한다.

- 기존 화면: `apps/mobile/src/features/recommendation/screens/ProductRecommendationScreen.tsx`
- 기존 API 호출: `apps/mobile/src/features/recommendation/services/productRecommendationService.ts`
- 기존 라우트: `ProductRecommendation`
- 기존 API:
  - `GET /api/products/recommendations`
  - `GET /api/products/liked`
  - `POST /api/products/{productId}/like`
  - `DELETE /api/products/{productId}/like`

기존 화면에서 가져갈 UI/UX:

- 기준 보고서 선택
- 추천 기준 룩/이미지 선택
- 카테고리 탭
- 정렬
- 제품 카드
- 제품 이미지
- 브랜드명/제품명/shade
- 색상 팔레트
- 가격
- 구매 링크
- 좋아요 버튼
- 로딩/빈 상태/재시도 상태

첫 구현 단계에서는 기존 화면을 버리고 새 화면을 만드는 방식이 아니라, 기존 화면을 제품 추천 허브로 복원한 뒤 section 단위로 확장한다.

## 5. AR 필터 기반 추천 설계

AR 필터 기반 추천은 사용자가 저장한 필터의 색상, 피니시, 강도, 부위 정보를 제품 추천에 사용하는 기능이다.

필요 데이터:

- 저장된 AR 필터 또는 AR 룩 ID
- 부위: 립, 블러셔, 아이섀도우, 아이라이너, 베이스
- 색상값
- 피니시: 글로우, 매트, 새틴, 쉬머 등
- 강도/opacity
- texture 또는 제형 관련 값

추천 방식:

1. 저장된 AR 필터에서 부위별 색상과 피니시를 추출한다.
2. 제품 카탈로그의 shade 색상과 비교한다.
3. 색상 유사도, 카테고리 일치, 피니시 일치, 사용자 취향을 조합해 점수를 계산한다.
4. 제품 카드에는 숫자 매치율보다 추천 이유 chip을 우선 표시한다.

주의:

- 현재 AR 저장 기능이 완벽하지 않으면 가짜 추천을 노출하지 않는다.
- 저장된 최종 AR 룩이 없으면 `AR 룩 만들기` CTA를 보여준다.
- 카테고리 대표색을 실제 제품 shade 색상처럼 사용하면 안 된다.

## 6. 네이버 API와 색상 임베딩

초기 기획에는 `필터 색상 임베딩 벡터 기반 네이버 API 연동`이 포함되어 있다. 구현 문서에서는 이 요구를 다음처럼 현실화한다.

- 색상 벡터는 AR 필터 색상과 자체/제휴 상품 shade 카탈로그를 비교하는 데 사용한다.
- 네이버 API는 상품 후보 탐색이나 시즌 트렌드 신호로 사용할 수 있지만, 네이버 상품명만 보고 `같은 색상`이라고 단정하지 않는다.
- 네이버에서 가져온 상품 정보는 약관과 종료 일정, 저장 가능 범위를 확인한 뒤 사용한다.
- 실제 추천 결과로 노출할 상품은 이미지, 구매 링크, 사용 권리, shade 근거가 확인된 카탈로그를 우선 사용한다.

즉, 사용자에게는 `네이버에서 긁어온 인기 상품`이 아니라 `내 AR 필터와 얼굴진단 결과에 근거가 있는 제품`으로 보여야 한다.

## 7. 개인화 추천 설계

### 서진님만을 위한 추천 제품

사용 데이터:

- 좋아요한 제품
- 많이 검색한 제품군
- 많이 클릭한 제품
- 저장한 룩 또는 필터
- 얼굴진단 리포트의 퍼스널 컬러/추천 무드

추천 방식:

- 사용자의 명시적 행동을 우선 반영한다.
- 최근 행동과 반복 행동을 구분한다.
- 데이터가 부족할 때는 시즌 상품과 AR 추천을 먼저 보여준다.
- 개인화 추천은 사용자가 끌 수 있어야 한다.

### 비슷한 컬러 취향 추천

사용 데이터:

- 퍼스널 컬러
- 선호 색상군
- 좋아요/클릭/저장 행동의 익명 집계

주의:

- 얼굴 유사도나 얼굴 사진 비교로 설명하지 않는다.
- 작은 그룹에서는 추천을 숨긴다.
- 개인을 추정할 수 있는 문구를 피한다.

## 8. 아우라딘 역할

아우라딘은 제품 추천 페이지 안에 있는 대화형 제품 추천 에이전트다.

역할:

- 사용자의 자연어 요청을 이해한다.
- AR 필터와 얼굴진단 리포트를 참고한다.
- 색상, 질감, 예산, 카테고리 조건을 해석한다.
- 조건에 맞는 제품을 추천한다.

예시:

```text
사용자: 피치빛 크림 블러셔 추천해줘
아우라딘: 저장한 AR 블러셔 색상과 가까운 피치/코랄 계열 크림 블러셔를 찾아줌
```

아우라딘은 제품 추천 페이지의 일부 기능을 확장하는 에이전트이며, 기본 제품 추천 허브 자체를 대체하지 않는다.

## 9. 구현 우선순위

### P0

- 홈의 `추천 제품` 버튼을 `ProductRecommendation`으로 복원
- 기존 제품 추천 화면/API/좋아요/카테고리 탭 유지
- 제품 검색 UI 추가
   - 아우라딘 edge-snapped 젤리 orb 추가
- 시즌 상품 section 추가
- AR 필터 데이터가 없을 때 정직한 empty state 제공

### P1

- 저장된 AR 룩 기반 추천 API 연결
- 부위별 AR 추천 rail 구현
- 실제 shade 색상 데이터 기반 색상 유사도 계산
- 좋아요 상태를 제품 추천/아우라딘/마이페이지에서 통합

### P2

- 좋아요/검색/클릭 기반 개인화 추천
- 비슷한 컬러 취향 사용자 추천
- 추천 이벤트 수집과 품질 지표

## 10. 완료 기준

- 홈의 `추천 제품` 카테고리에서 제품 추천 페이지로 정상 진입한다.
- 제품 추천 페이지에서 기존 추천 제품 목록이 정상 표시된다.
- 제품 카드에서 좋아요를 누르면 마이페이지 좋아요 목록과 연결된다.
- 아우라딘은 제품 추천 페이지 안의 진입점으로 제공된다.
- 시즌 상품 section은 AR 기능과 독립적으로 표시된다.
- 저장된 AR 필터가 없을 때 가짜 AR 추천을 보여주지 않는다.
- AR 필터가 저장된 경우 부위별 색상/피니시 기반 추천으로 확장 가능하다.
- 모바일 화면에서 로딩, 빈 상태, 오류, 새로고침, safe area가 깨지지 않는다.

## 11. 한 줄 설명

제품 추천 페이지는 사용자의 얼굴진단 리포트, 저장한 AR 필터, 제품 반응 데이터를 바탕으로 실제 구매 가능한 화장품을 추천하는 개인화 제품 탐색 허브다.
