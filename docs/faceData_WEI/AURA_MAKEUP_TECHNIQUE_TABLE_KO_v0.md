# AURA 측정→테크닉 매핑 테이블 v0 — 딥리서치 초안 (검수 전)

상태: 초안(2026-07-21). 리서치 1/2(눈+시각무게: 24출처·112클레임 중 25건 적대검증 → 22 확정·3 반박)과 2/2(눈썹·립·볼·베이스/윤곽: 22출처·95클레임 중 25건 검증 → 21 확정·4 기각) 모두 반영 완료. **모든 행은 잠정 — 사용자 검수 후 확정.**
근거 등급: A(동료평가 문헌·교육기관 교재) / B(저명 아티스트의 일관된 교육 콘텐츠) / C(업계 통념·단일 블로그). 검증 표기는 적대검증 투표(3-0 = 3인 만장일치 통과).
상위 문서: [얼굴 특징 프로파일 계획](./AURA_FACE_FEATURE_PROFILE_PLAN_KO_v0.1.md) · AR 골드 축은 [AR맞춤핏 계약 v0.2](./AR맞춤핏-계약초안-v0.md) 참조.

## 0. 리서치가 준 구조적 확신 두 가지

1. **"속성×밴드→테크닉" 테이블 구조 자체가 업계 표준 프레임이다** — Milady 미용학 교재(미국 주 면허시험 표준)가 눈 유형을 이산 카테고리로 나눠 유형별 보정 절차를 가르침. 단 교재는 수치 임계값을 주지 않으므로 밴드 경계는 우리 자체 분포로 정의(기존 계획과 일치). [A, 3-0]
2. **보정의 기본 연산자는 2개뿐** — 밝게(하이라이트)=전진·강조, 어둡게(섀도잉)=후퇴·축소. 아래 모든 행은 이 두 연산자의 위치·방향 조합이다. [A, 3-0]

⚠️ 전 행 공통 재서술 규칙: 원 출처의 "oval 이상형", "여성적=고대비" 같은 절대 규범·인구 통계는 채택하지 않는다. 방향 기제만 가져오고 목표는 항상 "본인 얼굴 내 상대 보정"으로 서술한다.

## 0.5 상충 유파 타이브레이크 캐스케이드 + 스타일 레인 3종 (2026-07-21 사용자 확정)

상충 행 판정 규칙 (순서대로 적용):
1. **근거 등급이 다르면 높은 쪽** (A > B > C).
2. **사용자 측정 밴드가 갈라주면 조건 분기** — 고정 비율(1:1:1 등)을 목표로 당기지 않고, "본인의 가장 큰 편차를 완화하는 방향"으로만. 방향은 균형 쪽, 목표값 없음, δ 소량. (상충처럼 보였던 것 상당수가 이 단계에서 조건부 규칙으로 해소됨 — 예: 블러셔 고배치 vs 저배치 = 본인 중안부 밴드로 분기)
3. **그래도 안 갈리면 보수적(δ 작은) 옵션이 기본값**, 다른 유파는 편집 화면 선택지로 노출.

**스타일 레인 3종** — 유파를 하나로 고르지 않고 셋 다 핏으로 제공한다. 측정 프로파일은 동일, 3층 매핑 엔진이 `styleLane` 파라미터로 δ 정책을 바꾼다:

| 레인 | 철학 | δ 정책 | 근거 연결 |
|---|---|---|---|
| `balance` (균형 보정형 — 기본값) | 본인 최대 편차 완화 | 편차 완화 방향, δ 소량, 목표값 없음 | Milady 보정 체계(A)를 자기참조로 재서술 |
| `youthful` (동안형 — K-뷰티) | 중안부 축소·하안부 짧게 (1:1:0.8 감각) | 중안부 축소 계열 규칙 활성(블러셔 고배치 등) | K/J-뷰티 유파(B/C). **명명된 스타일 옵션으로만 — 글로벌 기본값 금지** |
| `accent` (개성 강조형) | 우세 부위 존재감 극대화 | `dominantRegion`의 형태 보정 δ=0(교정 안 함 — 개성 보존) + 색·대비·intensity↑, 타 부위 절제. δ 부호 반전(편차 증폭) 금지 | W-4(눈>립 가중)·W-5(원포인트) + 시각무게 지도 활용 |

기본값은 `balance`(가장 보수적). `youthful`을 기본으로 승격하는 것은 시장별 트렌드 규범 채택이므로 금지 — 사용자 선택으로만.

## 3. 반박·기각된 것 (재유입 방지 기록)

- 둥근 눈 윙 각도 "20–30°" — 0-3 반박. 각도 수치는 전부 자체 실기기 튜닝으로.
- 올라간 눈꼬리 "짧은 플릭+아래꼬리 스머지" — 1-2 반박. 해당 밴드 공백 처리.
- "일반 캣아이는 hooded에서 후드에 삼켜진다" — 1-2 반박(bat-wing 기법 자체는 유효, 이 대비 주장만 기각).
- 모든 mm/도(°) 수치 파라미터는 단일 C급 출처 — 방향+부호만 문헌 근거, 크기(δ)는 AR맞춤핏 계약대로 실기기 슬라이더 실험으로.
