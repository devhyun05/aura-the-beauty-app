# AR Lower Eye Independence Design

## Goal

하단 아이섀도 룩이 이름에 맞는 가로 위치에 실제로 렌더링되도록 하고, 하단 아이라인 룩의 색상 변경이 상단 아이라인에 영향을 주지 않게 한다.

## Approved scope

- 하단 아이섀도에 `eyeshadowLowerShape` 전용 필드를 추가한다.
- 하단 아이섀도 모양은 `0=전체`, `1=앞쪽`, `2=중앙`, `3=뒤쪽`, `4=스모키` 다섯 가지다.
- 기존 6개 하단 아이섀도 룩은 모두 모양 값을 명시한다. `앞머리 밝힘`, `바깥 음영`, `언더 스모키`는 각각 앞쪽, 뒤쪽, 스모키 마스크를 사용한다.
- 하단 아이섀도 조절 화면에서 다섯 모양을 직접 선택할 수 있다.
- 하단 아이라인에 `eyelinerLowerColor` 전용 필드를 추가한다.
- 하단 아이라인 룩과 조절 화면은 `eyelinerColor`를 더 이상 변경하지 않는다.
- 새 모바일 기본값은 상·하단 모두 기존 기본색 `#181418`로 시작하지만 이후에는 독립적으로 변경된다.

## Architecture

기존 `LowerLidRenderer`와 `LowerLid.shader`를 유지한다. 새 하단 아이섀도 모양 값은 브리지에서 렌더러로 전달되고, 셰이더의 해부학적 가로 좌표 `u`(안쪽 0 → 바깥 1)에 적용되는 `LowerShadowHorizontalMask`가 위치를 결정한다. 세로 페이드와 마감 계산은 그대로 재사용한다.

하단 아이라인 색상은 모바일 룩과 조절축에서 전용 필드로 전송한다. Unity는 `eyelinerLowerColor`가 비어 있는 구형 payload에 한해서만 `eyelinerColor`로 폴백하여 저장된 예전 룩의 외형을 보존한다.

## Lower shadow masks

| 값 | 의미 | 가로 분포 |
|---:|---|---|
| 0 | 전체 | 눈머리·눈꼬리 경계만 페더하고 전 구간 |
| 1 | 앞쪽 | 안쪽 눈머리에서 중앙 전까지 감쇠 |
| 2 | 중앙 | 동공 아래 중심의 부드러운 벨 |
| 3 | 뒤쪽 | 바깥 절반에서 상승하고 눈꼬리 경계에서 페더 |
| 4 | 스모키 | 전 구간을 덮되 바깥쪽으로 갈수록 진해짐 |

모든 마스크는 기존 코너 페더를 곱하므로 메시 경계가 보이지 않아야 한다. 값이 생략되면 0이므로 기존 하단 아이섀도는 전체 모양을 유지한다.

## Data flow

1. 룩 카드 또는 세부 조절축이 `eyeshadowLowerShape`와 `eyelinerLowerColor`를 `FilterParams`에 기록한다.
2. React Native 브리지가 기존 필터 JSON 경로로 값을 Unity에 전달한다.
3. `BridgeMessages.FilterParams`가 값을 역직렬화한다.
4. `MakeupController`가 하단 아이라인 색상 폴백을 정규화하고 두 값을 `LowerLidRenderer`에 전달한다.
5. `LowerLidRenderer`가 머티리얼 프로퍼티를 설정한다.
6. `LowerLid.shader`가 하단 아이섀도 가로 마스크와 하단 아이라인 전용 색상을 사용한다.

## Compatibility and boundaries

- 새 라이브러리나 새 렌더러를 추가하지 않는다.
- 상단 아이섀도·상단 아이라인 렌더링과 필드는 변경하지 않는다.
- 구형 payload의 `eyeshadowLowerShape=0`은 전체 모양이며 기존 출력과 호환된다.
- 구형 payload에 `eyelinerLowerColor`가 없으면 상단 아이라인 색으로 폴백한다.
- 하단 강도가 0인 상태에서는 새 필드가 화면 출력에 영향을 주지 않는다.
- 기존 iOS 서명 및 Unity 씬 로컬 변경은 커밋하지 않는다.

## Verification

- 모바일 계약 테스트가 6개 하단 아이섀도 룩의 모양 배치와 하단 아이라인 색상 소유권을 검사한다.
- Unity 계약 러너가 새 브리지 필드, 렌더러 프로퍼티, 셰이더 마스크 함수, 구형 색상 폴백을 검사한다.
- 수치 계약은 앞·중앙·뒤 마스크가 각 목표 위치에서 가장 강하고 반대편에서는 충분히 약한지 검사한다.
- 모바일 TypeScript 타입체크와 기존 AR 계약 테스트를 실행한다.
- Unity 배치 컴파일로 C#과 셰이더 변경을 검증한다.

## Out of scope

- 하단 아이섀도의 색상 그라데이션, 다중 레이어, 입자 시스템
- 하단 아이라인의 별도 두께·워프 조절축
- 기존 상단 눈 메이크업 룩 재조정
