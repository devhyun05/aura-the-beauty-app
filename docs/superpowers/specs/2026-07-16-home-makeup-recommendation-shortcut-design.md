# 홈 메이크업 추천 바로가기 교체 설계

## 목표

홈 서비스 바로가기의 기존 `헤어 분석` 항목을 `메이크업 추천` 항목으로 완전히 교체한다. 사용자는 홈에서 한 번 눌러 기존 메이크업 추천 발견 화면으로 진입할 수 있어야 한다.

## UI

- 기존 항목의 위치, 크기, 표면 스타일, 간격, 누름 모션은 유지한다.
- 표시 문구와 접근성 라벨을 `메이크업 추천` 의미로 바꾼다.
- 새 아이콘 라이브러리를 추가하지 않고 현재 사용 중인 Lucide 아이콘 가운데 메이크업 추천에 맞는 아이콘을 사용한다.
- `헤어 분석` 항목은 홈 바로가기 목록에서 제거하며 별도 항목을 추가하지 않는다.

## 내비게이션과 코드 구조

- 홈 화면 prop과 서비스 바로가기 handler 이름을 `onPressMakeupRecommendation`으로 맞춘다.
- 홈 라우트는 기존 `MakeupRecommendation` 루트로 이동한다.
- 기존 헤어 분석 화면과 루트 자체는 삭제하지 않는다. 이번 변경은 홈 진입점만 교체한다.

## 검증

- 홈 화면 계약 테스트에서 바로가기 순서와 문구가 `메이크업 추천`으로 바뀌었는지 확인한다.
- handler 계약 테스트에서 해당 항목을 누르면 메이크업 추천 callback만 실행되는지 확인한다.
- 모바일 TypeScript 타입체크를 통과한다.
- 실기기에서 홈의 `메이크업 추천` 버튼을 눌러 추천 화면으로 이동하는지 확인한다.

## 범위 제외

- 공용 테마 및 디자인 시스템 변경
- 헤어 분석 기능 삭제
- 메이크업 추천 화면 내부 UI 또는 API 동작 변경
