# 퍼스널 컬러 보고서 일관성 및 축 그래프 설계

## 목표

카메라 측정 퍼스널 컬러가 유효할 때 보고서 상단의 퍼스널 컬러·톤 요약을 같은
측정값에서 생성한다. 추천 팔레트는 진단명이 아닌 추천 범위로 명확히 표시하고,
사용자가 각 축의 현재 위치와 용어를 이해할 수 있게 한다.

## 단일 기준

- 유효한 `measurements.personalColor.reported.tone`이 있으면 이를 보고서의 퍼스널
  컬러 기준으로 사용한다.
- 상단 `퍼스널 컬러`는 12톤 측정 라벨을 사용한다.
- 상단 `톤 요약`은 temperature/value/chroma 축의 현재 밴드를 풀어쓴 문구로 만든다.
- LLM은 퍼스널 컬러와 톤 요약을 재판정하거나 생성하지 않는다. 기기 측정값을
  메이크업 추천의 입력으로만 사용한다.
- 측정값이 없으면 퍼스널 컬러와 톤 요약은 `측정하지 못했어요`로 표시하며, LLM의
  사진 추정을 fallback으로 사용하지 않는다.

## 표시 용어

- `트루`는 괄호 없이 표기한다.
- `라이트`, `미드`, `딥`은 각각 `밝은 색`, `중간 밝기`, `깊은 색`으로 풀이한다.
- `뮤트`, `클리어`, `비비드`는 각각 `부드러운 색`, `맑은 색`, `선명한 색`으로 풀이한다.
- 팔레트 섹션 제목은 `추천 색 범위`로 한다. 각 항목은 `쿨 · 밝은 색 · 맑은 색`처럼
  풀어쓴 라벨과 대표 색 예시를 함께 보인다. 이는 진단이 아니라 현재 축의 중심값과
  인접 범위에서 고른 추천이라는 안내를 포함한다.

## 5축 그래프

모든 축 막대는 좌·중앙·우의 세 영역을 가진다. 현재 점이 속한 영역을 강조하고,
각 막대 아래에 현재 영역의 한국어 풀이를 표시한다.

- temperature: 쿨 / 뉴트럴 / 웜
- value: 밝은 색 / 중간 밝기 / 깊은 색
- chroma: 부드러운 색 / 맑은 색 / 선명한 색
- clarity: 소프트 / 균형 / 클리어
- contrast: 저대비 / 균형 / 고대비

## 검증

- 측정값이 있으면 상단 요약이 LLM 문자열 대신 측정값을 사용한다.
- `true` 12톤 라벨에 괄호가 없다.
- 팔레트의 축 조합이 사람 친화적 풀이와 예시를 제공한다.
- 각 축 값이 해당 영역 라벨로 안정적으로 변환된다.
