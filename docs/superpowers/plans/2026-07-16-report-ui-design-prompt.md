# 보고서 UI 디자인 생성 요청 프롬프트 (claude design / fable용)

용도: 아래 프롬프트 전문을 claude design(fable) 요청에 그대로 붙여 넣는다. `[사진]` 자리에는 실제 분석 사진 샘플 1~2장을 첨부하면 결과가 좋아진다.

---

## 프롬프트 전문

당신은 모바일 뷰티 앱의 "얼굴 분석 보고서" 화면을 디자인합니다. React Native(iOS) 세로 스크롤 단일 화면이며, 한국어 서비스입니다.

### 제품 맥락

- 사용자는 셀피 1장을 촬영하면 얼굴 측정(랜드마크·3D·색채)과 AI 해석이 합쳐진 **개인 분석 보고서**를 받습니다.
- 기존 화면의 실패 원인: 측정 수치(1.455, 62%, Lab 값 등)를 그대로 나열해 **사용자가 해석할 수 없는 숫자 보고서**였습니다.
- 이번 개편의 목표: **전문가가 옆에서 설명해주는 듯한 보고서.** 숫자는 단 하나도 화면에 노출하지 않고, 모든 특징을 서술형 문장 + 시각자료로 전달합니다.

### 절대 제약 (위반 시 디자인 폐기)

1. **측정 수치 노출 금지** — 비율·mm·px·%·각도·확률·신뢰도 등 **측정에서 나온 숫자**를 어디에도 표시하지 않는다. 경향은 마커 위치·색·서술 라벨로만 표현. (날짜·회차 같은 메타 숫자는 허용 — 금지 대상은 측정값이다.)
2. **단정 대신 서술** — "긴 얼굴형입니다"가 아니라 "하안부에 시선이 머무는 인상이에요"처럼 특징 서술 어조. 미추 판단(예쁘다/못생겼다) 금지.
3. **모든 시각자료는 데이터가 결정** — 장식이 아니라 실제 측정 데이터가 마커 위치·확대 영역·색을 결정하는 구조로 디자인(개발 시 내부 로직으로 렌더).
4. **측정 실패·판정 보류는 숨기지 않고 사유를 안내** — 판정 상태는 4계층이며 단정이 기본값이다: ① **단정**(정면에 가까운 정상 촬영 — 확신 있는 서술이 기본), ② **경계 유보**(촬영 오차 구간이 판정 경계에 걸침 — "가로형과 평균 사이"처럼 구간으로 서술), ③ **판정 보류**(촬영 각도 정보를 확인하지 못함 — 판정 자체를 보류하고 재촬영 유도), ④ **측정 실패**("헤어라인이 확인되지 않아 이 항목은 측정하지 못했어요" 스타일의 정직한 빈 상태). 유보·보류는 측정이 제대로 되면 나타나지 않는 촬영 품질 안내이지, 기본 어조가 아니다.
5. 혼합형 표현이 기본 — "당신은 X형" 단정 대신 "X 특징이 우세하고 Y 특징이 함께 보여요".
6. **색에만 의존하는 인코딩 금지(접근성)** — 스펙트럼 칩·블렌드 바·다이어그램의 의미는 색 외에 위치·형태·라벨로도 읽혀야 한다(색각 이상 대응). 다이내믹 타입(폰트 확대) 시 레이아웃이 깨지지 않는 구조.

### 화면 구조 — 7개 섹션 (순서 고정)

**S1. 분석 요약 (히어로)**
- 얼굴 사진(원형/카드) + 핵심 타입 한 줄(예: "부드러운 곡선형 · 여름 뮤트") + 두 문장 요약.
- 아래 4개 요약 칩: 얼굴형 / 퍼스널컬러 / 대비 인상 / 추천 무드.

**S2. 얼굴 사진 + 가늠선**
- 분석 사진 위에 세로 3분할 가로선(이마선·미간·코밑·턱끝)과 밴드가 오버레이된 전신 아님 얼굴 전체 뷰.
- 각 밴드에 서술 라벨("중안부", "하안부")만 — 비율 숫자 없음.
- 가늠선은 반투명, 사진을 해치지 않는 세련된 오버레이.
- **이마선(헤어라인) 없는 변형 포함** — 헤어라인은 촬영에 따라 확보되지 않을 수 있다. 미간·코밑·턱끝만으로 성립하는 부분 가늠선 레이아웃과, 빠진 선에 대한 제약 4 스타일 사유 안내.

**S3. 이목구비 분석 (보고서의 본체, 가장 긴 섹션)**
- 4개 그룹 카드: 상안부(이마·눈썹·눈) / 중안부(코·인중·볼) / 하안부(입술·E라인) / 외곽 라인(광대·턱).
- 각 그룹 카드의 구성:
  - **부위 확대 사진**: 원본 사진에서 해당 부위를 확대(crop)하고 가이드선(눈꼬리 기울기 선, 입술 라인 등)을 얹은 시각자료. 설명 문장과 1:1로 일치하는 근거 이미지 역할.
  - **스펙트럼 칩**: 축 하나당 가로 스펙트럼 바(양끝에 서술 라벨, 예: "내려간 눈꼬리 ↔ 올라간 눈꼬리") 위에 내 위치 표시. 숫자·눈금 없음. 표시는 판정 상태(제약 4)에 따라 3변형: **점 마커**(단정·기본) / **범위 밴드**(경계 유보 — 촬영 오차 구간을 트랙 위 반투명 밴드로) / **마커 없음+보류 캡션**(판정 보류 — 마커가 특정 범주를 가리키면 "보류" 서술과 모순되므로 숨김).
  - **서술 문단**: 2~3문장의 특징 설명 + 근거("눈꼬리 각도와 눈 사이 간격을 함께 보면…").
- 얼굴형은 블렌드 바(두 얼굴형의 혼합 정도를 한 바에 표현, 예: "타원형 우세 + 둥근형 특징")로.

**S4. 퍼스널 컬러**
- 12타입 중 내 타입 + 2차 톤을 블렌드 표현("여름 뮤트 중심, 겨울 브라이트에 걸침").
- 5축(온도·명도·채도·청탁·대비) 각각 스펙트럼 칩.
- 어울리는 팔레트 스와치(6~8색) / 피할 팔레트(3~4색).
- 측정 조건 안내 캡션 자리("이 결과는 촬영 조명 기준의 상대 진단이에요").

**S5. 체형 분석**
- 설문 기반 결과: 실루엣 타입(모래시계/역삼각/배/사과/직사각 중 1) + 골격 타입(스트레이트/웨이브/내추럴 중 1).
- 타입 일러스트 자리 + 스타일링 포인트 리스트(추천 3개·피하기 2개).
- 설문 미완료 시: 설문 유도 빈 상태 카드("7문항이면 체형 분석이 열려요").

**S6. 인상 종합**
- 이목구비+컬러+체형을 합친 종합 인상. 구성:
  - **지각 무게중심 다이어그램**: 얼굴 실루엣 아이콘 위에 시선이 먼저 가는 영역을 부드러운 하이라이트로 표시(눈가/중안부/하안부 등).
  - 인상 키워드 3~5개(칩): "또렷한", "곡선적인", "저대비" 등 기술적 형용사만(미추 아님).
  - 종합 서술 문단.

**S7. 스타일링 인사이트**
- **내추럴 / 글램 두 탭(또는 두 카드)** — 같은 얼굴에 대한 두 방향의 메이크업 전략.
- 각 탭: 대표 무드 한 줄 + 부위별(베이스·눈썹·아이·블러셔·립) 기법 카드. 각 카드에 "왜 나에게"(측정 근거 연결) 한 줄.
- 어조 구분 디자인: 근거가 강한 항목은 단정 어조, 업계 관행 항목은 "아티스트들은 ~을 권해요" 제안 어조 — 두 어조가 시각적으로 구분되게(예: 아이콘/배지).

### 시각 스타일 방향

- 뷰티/스킨케어 프리미엄 리포트 감성: 밝은 배경, 충분한 여백, 사진이 주인공.
- 기존 앱 자산: 포인트 컬러 하늘색 계열(#6ECBE8/#22AEDD), 마커 마젠타(#FF0B83) — 유지하되 마젠타는 마커 강조에만 절제 사용.
- 카드 기반 섹션, 섹션 헤더는 eyebrow(소제목)+타이틀 2단.
- 스펙트럼 칩·블렌드 바·다이어그램은 하나의 일관된 시각 언어로(같은 높이·라운드·마커 모양).
- 다크모드는 후순위(라이트 우선).

### 산출물

1. 전체 화면 세로 스크롤 목업(7섹션 전부 포함, 실제와 유사한 한국어 더미 카피).
2. 재사용 컴포넌트 시트: 스펙트럼 칩(점 마커/범위 밴드/보류 3변형) / 블렌드 바 / 부위 확대 카드(사진+가이드선) / 지각 무게중심 다이어그램 / 어조 배지 / 빈 상태 카드 / **이전 기준 안내 배지**(판정 기준 개정 후 열어본 과거 보고서에 붙는 캡션, 예: "이 판정은 이전 기준으로 측정된 결과예요") — 각 변형(variant) 포함. **S3 그룹 카드의 "사진 없는 변형" 필수**(부위 좌표가 없는 과거 보고서용 — 스펙트럼 칩+서술만으로 성립하는 레이아웃).
3. S3 그룹 카드 1개(예: 상안부)의 상세 확대 목업.

[사진] ← 실제 분석 사진 샘플 첨부 위치

## 프롬프트 사용 메모 (팀 내부용)

- 결과물이 숫자를 하나라도 그리면 제약 1을 인용해 재생성 요청.
- 개발 계약(Phase 0): 제목·마커·서술은 **하나의 판정 스냅샷**(측정 시점 동결, `faceLengthJudgment`+`judgmentVersion`)이 함께 결정한다 — 렌더 시점 재판정 금지. 디자인은 세 요소가 항상 같은 판정을 말한다고 전제하면 된다.
- 부위 확대 카드의 가이드선은 개발 시 SVG viewBox 확대 + 저장된 bbox·키포인트로 결정적 렌더([재구성 계획 §4.1](2026-07-16-face-report-redesign-plan.md)) — 디자인은 "어떤 가이드선이 어떤 설명과 짝인지"를 정의해주면 된다.
- S5 체형 일러스트는 기존 스텐실 AR의 실루엣 5종 분류와 라벨을 그대로 사용(`bodyProfile.ts`의 SILHOUETTE_STYLES).
