# 메이크업 추천 결과 화면 리디자인 — Claude 디자인 핸드오프

## 첨부 자료

- **현재 결과 화면 캡처(분석 결과)** — 개선 대상(before)
- **현재 진입 화면 캡처(분석 전 · 상황 선택)** — 진입→결과 흐름과 톤 참고용 (이 화면은 리디자인 대상 아님)
- **룩 이미지 3장** — 히어로에 넣을 실제 메이크업 결과 사진

| 파일 | 룩 role | 이름 |
|------|---------|------|
| `1_anchor_로지밸런스.png` | anchor | 가장 잘 어울리는 |
| `2_bold_클린스모키.png` | bold | 조금 더 과감한 |
| `3_discovery_뮤티드라일락.png` | discovery | 예상 밖의 발견 |

## 지금 결과 화면의 아쉬운 점 (개선 목표)

- **결과가 진입 화면보다 밋밋함** — 진입(상황 선택)엔 라이프스타일 사진·톡톡 튀는 키워드가 있는데, 결과는 무채색 회색 박스가 층층이 쌓여 단조롭고 정적.
- **히어로가 자주 비어 보임** — AI 메이크업 이미지가 준비 안 되면 큰 빈 사각형 + "이미지를 준비하지 못했어요"만 남아 허전함.
- **룩이 1개만 노출** — 데이터엔 3종(가장 잘 어울리는 / 과감한 / 예상 밖의 발견)이 있는데 화면엔 하나만.
- **개인화 근거가 안 보임** — 매치율·난이도·소요시간·추천 이유가 데이터엔 있지만 결과 화면엔 없음.
- **정보 위계 약함** — 핵심/질감/순서/마무리/제품이 다 비슷한 회색 카드라 눈이 쉴 곳도, 튈 곳도 없음.

## 프롬프트 (그대로 붙여넣기)

너는 뷰티 앱의 프로덕트 UI 디자이너야. **메이크업 추천 "결과 화면"** 을 리디자인해줘. 결과물은 **실제로 드래그·탭이 동작하는 자기완결형 `.dc.html` 인터랙티브 목업** 하나로 만들어줘.

**① 디자인 방향 (창의적으로 — 따라 그릴 레퍼런스는 없음)**

첨부는 **현재 앱 화면 캡처(진입·결과)** 와 **룩 이미지 3장**이야 — 화면 캡처는 개선 대상(before)이자 문맥이고, 룩 이미지는 히어로에 들어갈 실제 메이크업 결과 사진이야. 베낄 **디자인 레퍼런스는 일부러 안 줬어** — **너만의 새롭고 완성도 높은 비주얼을 자유롭게** 제안해줘. 한국 뷰티 앱다운 프리미엄 감성에 **깔끔하되 톡톡 튀고 만지는 재미**가 핵심이야. 컬러·타이포·모션은 하나의 일관된 시스템으로 네가 직접 정하되, 정적이지 않게 — 스크롤 등장·전환·마이크로 인터랙션과 디테일 있는 그림자로 "살아있는" 화면을 만들어줘. 한글 타이포 가독성은 챙기고, 현재의 밋밋함(무채색 회색 박스·검정 버튼·비어 보이는 히어로)에서 **확실히 벗어난 인상**을 목표로. 진입(상황 선택) 화면의 생기를 결과에서 **더 끌어올려**줘.

**② 화면 서사 (이 순서의 세로 스크롤)**

1. 히어로 — 오늘의 추천 룩 (이미지가 없을 때도 멋진 상태 포함)
2. 왜 당신께 맞는지 — 매치율 + 근거
3. 룩 3종 비교 — 좌표맵
4. 부위별 메이크업 — 색·질감·순서·제품
5. 공유 카드 → 하단 다층 CTA

**③ 반드시 다 보여줄 콘텐츠**

룩 3종 「가장 잘 어울리는 / 조금 더 과감한 / 예상 밖의 발견」, 각 룩의 **매치율·난이도·소요시간·추천 이유 2~3개**, 부위별(베이스·브로우·아이·치크·립) **색(이름+HEX, 예: 뉴트럴 베이지)·질감(예: 얇은 세미 글로우)·바르는 순서·마무리 코멘트·추천 제품(브랜드·제품명·가격·선택 기준, 예: 3CE 베어 커버 쿠션 22,080원)**.

**④ 필수 인터랙션 (실제 동작)**

1. **3-룩 스와이프 히어로** — 좌우로 넘기면 이미지·타이틀 전환(첨부 룩 이미지 3장 사용). '예상 밖의 발견'은 살짝 가려뒀다가 **탭하면 화려하게 리빌**(서프라이즈 연출). **이미지 로딩/실패 상태도 의도된 스켈레톤·플레이스홀더로** 설계(현재처럼 빈 사각형 금지).
2. **비포/애프터 슬라이더** — 원본 얼굴 ↔ AI 메이크업을 손가락으로 문질러 갈라 비교.
3. **매치율 게이지 + 근거 칩** — "웜톤·둥근 눈매에 92% 매치" 식 원형/바 게이지 + 근거 pill.
4. **부위 탭투점프** — 얼굴 일러스트에서 눈/입술/볼 탭 → 해당 가이드 카드로 스크롤.
5. **룩 좌표맵** — 자연↔개성 / 캐주얼↔글램 2축에 3룩을 점으로 배치, 탭하면 해당 룩으로 히어로 전환.
6. **공유용 세로 카드** — 프레임 + 매치율 + 3룩 썸네일.
7. **다층 CTA** — 메인 "AR로 입어보기" + 보조 저장·공유.

**⑤ 제약**

모바일 세로, 폭 **390px** 기준. 외부 리소스·CDN 없이 단일 `.dc.html`(인라인 CSS/JS), 이미지는 첨부본을 data URI나 플레이스홀더로. **React Native로 이식 가능한 구조**(제스처·애니메이션 로직 분리). 브라우저에서 열면 위 인터랙션이 실제로 동작해야 함.
